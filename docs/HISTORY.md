# Repository history

This repository starts from the reviewed Grafly source snapshot prepared on
2026-11-03, with selected earlier development history retained as its ancestry.
The default branch contains the complete current product.

Earlier commits were filtered to remove retired service and authentication
integrations, deployment files, machine-specific configuration, operational
notes, obsolete source maps, and generated binaries. Commits that became empty
were omitted. Historical snapshots therefore document the retained source
changes and are not supported standalone releases.

Author names and dates are retained. The maintainer's email uses the GitHub
noreply address. Commit bodies and old pull-request merge identifiers were
omitted; subjects containing operational details were generalized. Commit IDs
changed, and source references were updated where the referenced change remains.
The original repository, pull requests, logs, tags, and complete commit metadata
are preserved separately in a private archive and were not imported here.

This filtering does not change licensing or attribution. Grafly retains the
original Graft MIT license and third-party notices, including XERJ's Apache-2.0
license and historical D3 attribution. See `LICENSE` and `THIRD_PARTY_NOTICES`.
